# Welcome to the LDT4SSC Knowledge Hub

The Knowledge Hub is the central reference point for **Local Digital Twins for Smart and
Sustainable Communities (LDT4SSC)**. It collects the project's outputs — strategy, guidance,
technical resources and pilot work — and keeps them openly available for reuse beyond the
project's lifetime.

## Purpose

The Knowledge Hub is more than a repository. By consolidating resources in one place, it:

- **Documents the strategy** — mission, vision, impact assessment and the sustainability
  framework guiding the project;
- **Connects the ecosystem** — linking LDT4SSC to related European initiatives, standards and
  infrastructures;
- **Supports interoperability** — making requirements, specifications and use cases openly
  available;
- **Equips pilots** — guidance, technical recommendations and demonstrators;
- **Enables reuse** — so outputs remain usable after the project ends.
