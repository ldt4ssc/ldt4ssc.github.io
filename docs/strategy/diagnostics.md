# Ecosystem diagnostics

Where the European LDT ecosystem stands today — the strengths it can build on, the weaknesses
that constrain it, and the landscape it competes in. The analysis was developed through a
consortium workshop in March 2026, grounded in desk research and landscape analysis.

It operates at **two interdependent levels**: the broader LDT ecosystem, and the specific
LDT4SSC assets and services — treated together under each heading because they condition one
another.

---

## SWOT analysis

Each dimension is read at two levels: the <span class="level-dot ecosystem">LDT ecosystem</span>
as a whole, and <span class="level-dot assets">LDT4SSC's own assets and services</span> — they
condition one another, so the tables below set them side by side.

=== "Strengths"

    **Internal.** Properties that are difficult to replicate in the short term.

    The ecosystem and the LDT4SSC asset portfolio derive **institutional credibility** from
    mutually reinforcing properties: EU programme funding, community co-production, and
    structural integration with prior and ongoing initiatives such as [SIMPL](https://simpl-programme.ec.europa.eu/), the [LDT Toolbox](https://interoperable-europe.ec.europa.eu/collection/ldttoolbox),
    [DS4SSCC](https://www.ds4sscc.eu/) and Living-in.EU. Validated through concrete pilot demonstrators, this anchoring
    reduces regulatory and political barriers to adoption among public administrations.

    **Technical openness** is the second core strength. Open-source foundations prevent vendor
    lock-in; grounding in [**MIMs Plus**](https://living-in.eu/group/7/commitments/mims-plus-version-8-2025), [**NGSI-LD**](https://ngsi-ld.org/) and [**FAIR principles**](https://www.openscience.eu/article/infrastructure/guide-fair-principles) ensures
    interoperability and data quality; alignment with digital sovereignty makes the assets
    compatible with [Gaia-X](https://gaia-x.eu/), [SIMPL](https://simpl-programme.ec.europa.eu/) and the [EU Data Strategy](https://digital-strategy.ec.europa.eu/en/policies/strategy-data) — properties proprietary
    non-European alternatives do not match.

    | <span class="level-ecosystem">LDT ecosystem</span> | <span class="level-assets">LDT4SSC assets &amp; services</span> |
    |---|---|
    | EU policy alignment | Institutional trust, legitimacy and EU ecosystem anchoring |
    | Institutional credibility | Technical openness, standards alignment and EU sovereignty |
    | Open-source foundations | Centralised asset management and discoverability |
    | Technical maturity | |
    | Growing pilot portfolio | |
    | Community infrastructure and facilitation capacity | |

=== "Weaknesses"

    **Internal.** The gaps the strategic priorities are built to address.

    Local communities face significant **structural disparities in digital maturity** (as reflected in [LORDIMAS](https://data.europa.eu/en/news-events/news/lordimas-digital-maturity-assessment-tool-regions-and-cities) assessments). Current
    resources and onboarding pathways are oriented toward technically advanced frontrunner
    municipalities, creating a **participation ceiling that limits equitable access**. Business
    models for ecosystem-based LDTs remain underdeveloped, and uneven post-project funding
    access leaves long-term continuity uncertain.

    A **cross-disciplinary skills deficit** may sustain dependency on external consultancy,
    limiting communities' potential for growth — while technical fragmentation, legacy
    infrastructure and proprietary inertia challenge the federation promise.

    | <span class="level-ecosystem">LDT ecosystem</span> | <span class="level-assets">LDT4SSC assets &amp; services</span> |
    |---|---|
    | Digital maturity disparities and onboarding gaps | Technological robustness and relevance |
    | Technical fragmentation and interoperability readiness | Adoption, perception and ethical limitations |
    | Underdeveloped business models | Positioning and differentiation |
    | Uneven funding access | Structural ecosystem readiness gaps |
    | Missing internal value proposition | |
    | Documentation and communication | |
    | Internal leadership and network-building capacity | |
    | Cross-disciplinary skills deficit | |
    | Data quality and provenance standards | |
    | Environmental footprint of LDT infrastructure | |
    | Citizen co-production deficit | |

=== "Opportunities"

    **External.** Openings that depend on timing.

    New regulatory instruments are creating **structural demand**, while growing urban
    challenges create market pull. European city networks bring independent convening power, and
    the EU LDT model has potential as a **global norm-setting platform**.

    | <span class="level-ecosystem">LDT ecosystem</span> | <span class="level-assets">LDT4SSC assets &amp; services</span> |
    |---|---|
    | New regulatory instruments creating structural demand | Compatibility with [LDT CitiVERSE EDIC](https://ldtcitiverse-edic.eu/) as a pathway for sustainability |
    | EU institutional co-investment and adjacent ecosystem resources | Open to external developers and service provisioning, and to external contributions |
    | Growing urban challenges creating market pull | |
    | Sectoral expansion into energy, mobility and environment | |
    | Independent convening power of European city networks | |
    | EU LDT model as global norm-setting platform | |

=== "Threats"

    **External.** Risks requiring active management.

    **EU funding cycle discontinuity** and public financing contraction sit alongside
    the pull of proprietary platform alternatives. Standards fragmentation across the
    broader EU landscape, stakeholder fatigue, and an expanding cybersecurity attack surface
    from federation all compound the risk — as does legal uncertainty around [AI Act](https://eur-lex.europa.eu/eli/reg/2024/1689/oj/eng) compliance.

    | <span class="level-ecosystem">LDT ecosystem</span> | <span class="level-assets">LDT4SSC assets &amp; services</span> |
    |---|---|
    | EU funding cycle discontinuity and public financing contraction | Fragmentation and choice overload |
    | Proprietary platform alternatives | EU funding dependency and long-term viability |
    | Technical standards fragmentation across the broader EU landscape | Security risks from networked LDTs |
    | Stakeholder fatigue across overlapping initiatives | |
    | Geopolitical, climate and force majeure disruptions | |
    | Cybersecurity threat landscape and federation attack surface | |
    | [AI Act](https://eur-lex.europa.eu/eli/reg/2024/1689/oj/eng) compliance obligations and legal uncertainty | |

duplicating it.
